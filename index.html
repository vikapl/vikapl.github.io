AI-Assisted DevOps Automation

As the team adopted Claude Code, human PR review became the bottleneck. I customized Anthropic's Claude Code GitHub Action into a review agent running across 30 repositories. On every PR it checks the change against the linked Jira ticket and flags exposed secrets, with separate prompts for infrastructure and application code. It's advisory by design, so a false positive never blocks a merge, and it has caught real requirement gaps and exposed secrets.

Canary Releases for ML Predictions

A Lambda serving SageMaker model predictions used to ship all at once, and a bad model meant a manual redeploy. I owned the release path: CodeDeploy now sends 10% of traffic to a new version for 15 minutes while CloudWatch watches error rate and p95 latency. If errors pass 0.5%, it rolls back automatically. The team now ships model updates during business hours.

  1. New version
    Lambda + SageMaker model
  2. Canary
    10% of traffic · 15 min
  3. CloudWatch check
    error rate · p95 latency
  4. Auto-decide
    pass → 100% · >0.5% errors → rollback
