# Vika Plamadeala — DevOps Portfolio

Personal portfolio site for Vika Plamadeala, DevOps Engineer.

## Structure

- `index.html` — the site (single page, responsive: one layout collapses to mobile via a CSS breakpoint)
- `assets/style.css` — all styling
- `assets/vika-photo.jpg` — hero photo
- `resume/Vika-Plamadeala-Resume.pdf` — downloadable résumé
- `resume/build_resume.py` — the ReportLab script that generates the résumé PDF from source content, so it can be regenerated after edits

## Content

Three in-depth case studies (a production canary-release pipeline, an AI-assisted PR review agent, and a policy-gated EKS incident-remediation project), plus experience, skills, certifications, and contact info.

## Hosting

This repo is served via GitHub Pages. Since it's not named `<username>.github.io`, it's served as a project page rather than the account's root page — check the repo's **Settings → Pages** to confirm the source branch and see the live URL.
